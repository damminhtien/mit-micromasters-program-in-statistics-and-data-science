# 6.86x Machine Learning with Python

Personal notes and project material for MITx 6.86x, covering the path from linear models to neural networks. The focus is on understanding assumptions, objective functions, generalization, and implementation trade-offs.

> **Status:** The repository contains selected lecture assets, notes, and projects. It is a learner archive, not a complete replacement for the official course.

## What you will find

- Linear classification, regression, loss functions, regularization, and generalization.
- Recommender systems and nonlinear models.
- Feedforward networks, recurrent neural networks, and convolutional networks.
- Python projects and compact revision sheets.
