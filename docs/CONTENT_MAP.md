# Content map

This page is the canonical navigation layer for the archive. It distinguishes local notes from external course material and incomplete sections.

## Recommended learning order

1. [Probability](../6.431x_probability/README.md) — distributions, conditioning, expectation, limit theorems, and stochastic processes.
2. [Fundamentals of Statistics](../18.6501x_statistics/README.md) — inference, estimation, testing, and Bayesian statistics.
3. [Machine Learning](../6.86x_machinelearning/README.md) — models, objectives, generalization, and neural networks.
4. [Data Analysis](../6.419x_dataanalysis/README.md) — applied modeling, high-dimensional data, networks, and time series.
5. [Capstone revision](../ds.cfx_capstoneexam/README.md) — use only after checking current official requirements.

For a compact general orientation, see the [study guide](../resources/Study_guide.md).

For runnable examples, use the [Data Analysis project runbook](../6.419x_dataanalysis/projects/README.md) or the [Machine Learning project guide](../6.86x_machinelearning/projects/README.md).

## How to read a note

Look for four things before trusting a page: source/cohort, assumptions, whether the result is a definition or a heuristic, and whether the example has been independently checked. If any of these are missing, open an issue rather than silently treating the note as canonical.
