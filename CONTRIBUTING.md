# Contributing

Thank you for helping make this archive easier to learn from.

## Good contributions

- Fix a broken local link or missing image reference.
- Add a concise explanation of a difficult concept, with assumptions and a source.
- Add a notebook that runs from a fresh environment and states its dependencies.
- Improve a course index without claiming incomplete material is official.
- Report a mathematical or attribution problem through an issue.

## Please do not add

- Secrets, private course content, access-controlled exports, or personal identifiers.
- Solutions to active graded assessments when publication would undermine course rules.
- Copied material without attribution or a clear redistribution basis.
- Generated folders such as `.codex/` or `graphify-out/`.

## Before opening a pull request

1. Run `python scripts/check_content.py`.
2. Check the rendered Markdown, especially formulas and images.
3. Include the source, cohort/date, and ownership status for imported material.
4. Keep the change focused and describe what a learner gains from it.

For a small correction, opening an issue is welcome even if you do not want to prepare a pull request.
