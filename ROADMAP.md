# Roadmap

The project should become a trusted, searchable study hub rather than a large folder of exports.

## Shipped in this cleanup

- Correct program map and separate official, personal, and external material.
- Add a canonical content map, provenance policy, citation file, and contribution guide.
- Repair local navigation and replace missing external image references with explicit notices.
- Make the OceanFlow notebook portable through `OCEANFLOW_DATA`.
- Add a dependency baseline and CI checks for Markdown targets and notebook portability.

## Next milestones

- [ ] Publish one fully verified “flagship chapter” with rendered formulas, worked examples, and a runnable notebook.
- [ ] Rename or wrap long Notion-export filenames behind stable, human-readable entry points.
- [ ] Add per-course coverage tables with source cohort, last review date, and confidence level.
- [ ] Re-run project notebooks from a clean environment and record the results.
- [ ] Review large PDFs and model artifacts for redistribution rights and clone size.
- [ ] Add a small set of visual summaries or interactive examples that teach one concept end to end.

## Definition of done for a study chapter

A chapter is ready to promote when it has a working local path, a named source, explicit assumptions, checked formulas, at least one independently runnable example, and no unresolved ownership question.
